🗄️ 4. PostgreSQL Relational Schema & Ledger Design

PostgreSQL 16 with 14 production tables, Flyway migrations (V1–V9), and append-only ledgers

activity_logs
Carbon Logs
  • 🔑 idUUID PK
  • 🔗 user_idUUID FK (users)
  • categoryVARCHAR(20)
  • factor_keyVARCHAR(60)
  • quantityNUMERIC(10,2)
  • co2_kgNUMERIC(10,3)
  • activity_dateDATE
  • deleted_atTIMESTAMPTZ
emission_factors
Reference Math
  • 🔑 idUUID PK
  • categoryVARCHAR(20)
  • factor_keyVARCHAR(60)
  • factor_kg_per_unitNUMERIC(10,4)
  • unitkm, kWh, item
  • regionGLOBAL, IN, etc.
  • activeBOOLEAN
credit_ledger
Immutable Ledger
  • 🔑 idUUID PK
  • 🔗 user_idUUID FK (users)
  • deltaINTEGER (+ / -)
  • balance_afterINTEGER
  • reasonVARCHAR(200)
  • rule_keyVARCHAR(60)
  • created_atTIMESTAMPTZ

Utility Ingestion
  • 🔑 idUUID PK

  • blob_urlVARCHAR(1000)
  • statusUPLOADED..CONFIRMED
  • units_consumedNUMERIC(12,2)
  • bill_amountNUMERIC(12,2)
  • confidenceNUMERIC(5,4)

Dynamic AI Prompts
