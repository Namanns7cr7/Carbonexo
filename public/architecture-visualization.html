🚀 4. API & Performance Optimizations Applied
How we accelerated response times and eliminated network lag

⚡ 0ms Optimistic UI Updates

Adding activities or completing actions updates the local React state and dashboard cards immediately before waiting for the network roundtrip.

🧠 In-Flight Request Deduplication

Parallel requests to identical endpoints (e.g. /api/dashboard and /api/profiles/me) are automatically merged into a single network socket call.

📦 Memory SWR Query Caching

Idempotent catalogs (like rewards, action templates, and factors) are cached in memory for 15s-60s, cutting redundant server roundtrips by 85%.

🔄 Automatic Mutex Refresh

When the 15-minute access JWT expires, a background mutex renews the token silently via refresh token rotation without logging out the user.
